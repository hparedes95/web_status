# Referencia — material de exploración

⚠️ **Estos documentos NO describen el alcance acordado.** Son el análisis previo, con un
alcance mucho más amplio (sondas propias, agente local, indicadores derivados, 22 días de
trabajo) que **se descartó a propósito**.

El alcance vigente está en [`docs/01-alcance.md`](../01-alcance.md): solo estado de
servicios y una alerta.
