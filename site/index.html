Telefonía y energía no se detectan solas. No existe API de operadoras ni de distribuidoras eléctricas: esas luces solo se encienden si alguien las marca. Para hacerlo, abre una issue en el repositorio con la etiqueta caida:vodafone (o caida:telefonica, caida:energia) y ciérrala cuando se resuelva. El panel se actualiza al momento.
